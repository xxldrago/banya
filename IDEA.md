# Техническое задание
## Портал для аренды бань и саун
**Версия:** 1.0  
**Дата:** 13.10.2026  
**Назначение документа:** подробная спецификация для разработки веб-портала силами ИИ-разработчика / команды разработки.

## 1. Общие сведения
- Название проекта: Портал для поиска и аренды бань и саун
- Цель проекта: Создать веб-платформу, которая позволяет пользователям находить бани и сауны, фильтровать по дате/времени/доступности/вместимости/цене/услугам, просматривать карточки, бронировать онлайн, общаться с владельцем в чате после бронирования. Владелец — управлять объектами, календарём, бронированиями, услугами, фото, отзывами, промокодами, рекламой, уведомлениями. Админ — управлять платформой, модерацией, пользователями, бронированиями, финансами, рекламой, аналитикой.
- Тип продукта: Адаптивный веб-сайт + личный кабинет пользователя + кабинет партнёра/владельца + административная панель + backend API
- Язык интерфейса: русский
- Валюта: рубли
- Часовые пояса: учитывать часовой пояс города/объекта
- География: города РФ, архитектура должна поддерживать добавление других городов и регионов

## 2. Роли и права доступа
- Гость: просмотр каталога, фильтры, карточки, отзывы, контакты (если не скрыты), переход к бронированию, регистрация/авторизация
- Авторизованный пользователь/клиент: всё выше + бронирование, доп.услуги, история бронирований, чат с владельцем после бронирования, отзывы после завершения визита, избранное, промокоды, профиль/уведомления
- Владелец/партнёр (физлицо/самозанятый/ИП/ООО): профиль компании, объекты, цены/фото/описание/удобства, календарь доступности, iCal-синхронизация, ручные бронирования, бронирования, доп.услуги, ответы на отзывы, промокоды, платное продвижение, статистика, уведомления в мессенджеры, контакты
- Администраторы: Суперадминистратор, Модератор контента, Оператор поддержки, Финансовый администратор, Маркетолог, Контент-менеджер

## 3. Пользовательская часть
- Главная: выбор города, фильтр, подборки, рекламные карточки, новые объекты, отзывы, SEO
- Каталог: фильтры по дате/времени/длительности/кол-ву человек/цене/услугам + доп.фильтры, сортировка, карта с кластеризацией
- Карточка объекта: галерея, видео, описание, удобства, правила, цены/тарифы, доп.услуги, календарь доступности, отзывы/оценки, похожие, избранное/поделиться
- Бронирование: режимы (заявка с подтверждением / мгновенное с онлайн-оплатой / оплата на месте), форма, проверка доступности/вместимости/минимальной длительности/пересечений, статусы, чат после создания

## 4. Личный кабинет клиента
Профиль, мои бронирования, чаты, избранное, отзывы, промокоды, уведомления, настройки, поддержка

## 5. Кабинет владельца/партнёра
Регистрация с верификацией, управление объектами, календарь (день/неделя/месяц, блокировки, рабочие часы), ручные бронирования, iCal импорт/экспорт с обработкой конфликтов, доп.услуги, фото/видео с модерацией, ответы на отзывы, промокоды, платное продвижение (разные форматы, баланс, статистика), аналитика по карточке, настройка уведомлений в мессенджеры, реквизиты для выплат

## 6. Административная панель
Дашборд, пользователи, партнёры, модерация объектов/фото/видео/отзывов, управление бронированиями/платежами/возвратами, реклама, промокоды платформы, справочники, контент/SEO, тикеты поддержки, журнал аудита, настройки платформы, антифрод

## 7. Модель данных (ключевые сущности)
users, partners, cities, venues, venue_photos, venue_videos, venue_amenities, amenities, extra_services, venue_extra_services, bookings, booking_extra_services, booking_status_history, payments, refunds, payouts, reviews, review_responses, favorites, chats, chat_messages, promo_codes, ad_campaigns, notification_logs, ical_sync_jobs, admin_audit_logs, support_tickets и др.

## 8. API
REST API /api/v1, JWT авторизация, ролевая модель, валидация, rate-limit, защита от IDOR, OpenAPI/Swagger

## 9. Архитектура (рекомендуемая)
Frontend: React/Next.js + TypeScript  
Backend: Node.js + NestJS (или Laravel/Django/FastAPI)  
БД: PostgreSQL  
Кэш: Redis  
Поиск: Meilisearch/Elasticsearch  
Хранилище: S3-совместимое  
Очереди: BullMQ/Redis Queue  
WebSocket для чата  
Docker, CI/CD

## 10. Нефункциональные требования
Адаптивность, производительность (поиск <1с, API 95% <300-500мс), доступность 99.5%+, резервное копирование, логирование/мониторинг, безопасность (хеши паролей, XSS/CSRF/SQLi, защита вебхуков платежей), персональные данные, 2FA для владельцев/админов

## 11. MVP состав
Выбор города, каталог с фильтрами (дата/время/кол-во/цена/услуги), карточка объекта, форма бронирования, чат после бронирования, ЛК клиента, регистрация партнёра, добавление объекта, календарь, просмотр/ручные бронирования, отзывы+ответы, базовая админка, email-уведомления, статистика просмотров карточки

## 12. Критичные правила
- Исключить двойные бронирования (транзакции/блокировки/проверка пересечений)
- Не показывать недоступные слоты/объекты как доступные
- Строгая проверка прав доступа (IDOR)
- Атомарность критичных операций
- История статусов/критичных действий
- Проверяемость платежных статусов
