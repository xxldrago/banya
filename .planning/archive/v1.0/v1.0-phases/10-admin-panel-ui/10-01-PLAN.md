# Phase 10 Plan 01: Admin Panel UI

## Overview

Build the administrative panel UI pages.

## Tasks

### Task 1: Admin layout + navigation shell (ADMIN-01)
- Create /admin layout with sidebar navigation
- Protected route wrapper (ADMIN role required)
- Navigation: Dashboard, Users, Venues, Bookings, Reviews, Payments, Promo Codes, Chat, Settings

### Task 2: Dashboard page (ADMIN-02)
- Statistics cards (users, venues, bookings, revenue)
- Recent bookings table
- Revenue chart placeholder

### Task 3: Users management page (ADMIN-03)
- List all users with role filter
- Search by email/name
- Edit user role
- Block/unblock user

### Task 4: Venues moderation page (ADMIN-04)
- List venues with status filter
- Approve/reject venues
- Search by city/title
- View venue details

### Task 5: Bookings management page (ADMIN-05)
- List all bookings with status filter
- Search by venue/user
- Cancel bookings
- View booking details

### Task 6: Reviews moderation page (ADMIN-06)
- List reviews with status filter
- Approve/reject reviews
- View review details

### Task 7: Payments management page (ADMIN-07)
- List payments with status filter
- Search by booking/user
- View payment details
- Refund support

### Task 8: Promo codes + Chat + Settings (ADMIN-08)
- Manage platform promo codes
- View all chat conversations
- Platform settings
