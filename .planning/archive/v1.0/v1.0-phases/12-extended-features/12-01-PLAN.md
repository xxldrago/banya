# Phase 12 Plan 01: Extended Features

## Overview
Implement additional features: iCal sync, partner review responses, paid promotion, venue statistics/analytics.

## Tasks
1. iCal sync (EXT-01)
   - Add ICalSyncJob service
   - Import venue calendar from external iCal URL
   - Export venue availability to iCal format
   - API endpoints: GET/POST /api/v1/ical/jobs, PUT /api/v1/ical/sync
2. Partner responses to reviews (EXT-02)
   - Extend ReviewResponse model (already in Phase 11)
   - Partner can respond to reviews (already has API from Phase 04)
   - Real-time updates for reviews
   - Frontend for partner review response
3. Paid promotion (EXT-03)
   - Add BoostCampaign model
   - Venue can boost to top positions
   - Daily/weekly/monthly pricing
   - API endpoints for promotion management
4. View statistics/analytics (EXT-04)
   - Venue analytics: views, bookings, revenue per day
   - System-wide admin stats
   - Search analytics (top venues, keywords)
