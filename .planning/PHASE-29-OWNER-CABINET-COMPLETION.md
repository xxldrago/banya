# Phase 29: Owner cabinet completion

## Overview
Глубокая аналитика владельца, расписание/исключения, ручные брони UI, экспорт, шаблоны, виджеты, тарифы UI.

## Goal
- Глубокая аналитика: просмотры карточки, уникальные, фото/видео просмотры, клики по телефону/адресу, избранное, переходы к брони, брони, конверсия, источники трафика, популярные даты/фильтры, динамика.
- Расписание работы: рабочие часы, выходные, повторяющиеся блокировки, исключения.
- Ручные бронирования (UI): выбор объекта, дата/время, клиент (существующий/новый), гости, услуги, цена, статус, блокировка интервала.
- Экспорт бронирований CSV/Excel.
- Шаблоны сообщений, автоответы.
- Виджет онлайн-записи для сайта владельца.
- Тарифы UI (по дням/часам, спецпредложения).
- Рейтинг качества объекта.

## Requirements
OWNER-CAB-01..07

## Success Criteria
1. Аналитика показывает все метрики.
2. Расписание настраивается и применяется.
3. Ручные брони создаются без конфликтов.
4. Экспорт работает.
5. Виджет встраивается на внешний сайт.

## Key Tasks
- Расширение API аналитики.
- UI расписания (день/неделя/месяц).
- UI ручных броней.
- Экспорт CSV/Excel.
- Виджет (iframe/script).
- Тарифы UI.
