# Phase 24: Contact visibility and venue media

## Overview
Скрытие контактов до бронирования, категории фото, загрузка видео, полноэкранный просмотр галереи.

## Goal
- Настройка владельца «показывать телефон только после бронирования».
- Заглушка контактов до брони + кнопка «Забронировать, чтобы увидеть».
- Категории фото (парная, отдых, бассейн, территория, экстерьер, доп. зоны).
- Загрузка видео (MP4 или ссылка на хостинг).
- Полноэкранный просмотр галереи.
- Оптимизация изображений (сжатие, превью).

## Requirements
VENUE-MEDIA-01..04

## Success Criteria
1. Контакты скрываются до брони (настраиваемо).
2. Фото группируются по категориям.
3. Видео загружается и модерируется.
4. Галерея открывается fullscreen.

## Key Tasks
- Добавить поле showContactsBeforeBooking в Venue.
- Категории фото (enum/model).
- Загрузка видео (S3/Cloudinary).
- Fullscreen gallery компонент.
- Оптимизация изображений.
