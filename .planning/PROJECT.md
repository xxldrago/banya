# Project: Портал для аренды бань и саун

## Core Value
Создать удобную и надёжную платформу для поиска и онлайн-бронирования бань и саун с минимальным числом действий для клиента и понятным инструментарием для владельца.

## What This Is
Веб-платформа для поиска, фильтрации, бронирования бань и саун с личным кабинетом пользователя, кабинетом партнёра/владельца и административной панелью.

## Requirements

### Validated
- [ ] Базовая архитектура проекта и структура

### Active
- [ ] Выбор города и поиск по каталогу
- [ ] Фильтрация по дате/времени/вместимости/цене/услугам
- [ ] Карточка объекта с фото, удобствами, правилами, календарём доступности
- [ ] Онлайн-бронирование с проверкой доступности и предотвращением пересечений
- [ ] Чат между клиентом и владельцем после бронирования
- [ ] Личный кабинет клиента
- [ ] Кабинет владельца/партнёра (объекты, календарь, бронирования, доп.услуги)
- [ ] Административная панель
- [ ] Синхронизация календаря через iCal
- [ ] Отзывы и рейтинги с модерацией
- [ ] Промокоды и платное продвижение
- [ ] Уведомления
- [ ] Платежи (карта/СБП)
- [ ] Ролевая модель доступа

### Out of Scope
- Мобильное приложение (только веб)
- Агрегация из сторонних систем
- Кредитование/рассрочка

## Context
Язык: русский, валюта: рубли, география: РФ.

## Key Decisions
| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Web-first (React/Next.js + TypeScript) | Адаптивность, SEO, быстрая разработка | — Pending |
| REST API /api/v1 (JWT) | Стандарт, понятная авторизация | — Pending |
| PostgreSQL + Redis + S3 | Надёжность, кэш, хранение медиа | — Pending |
| Предотвращение двойных броней через транзакции | Критичное требование | — Pending |

## Constraints
- Нельзя допускать двойных бронирований
- Не показывать недоступные слоты
- Строгий контроль прав доступа
- История статусов и критичных действий
