# Phase 27: Chat enhancements

## Overview
Вложения в чате, статусы прочтения, быстрые ответы/шаблоны, антиспам.

## Goal
- Отправка изображений и документов в чате.
- Статусы доставки/прочтения.
- Быстрые ответы и шаблоны для владельца.
- Антиспам-фильтр.
- Закрытие чата при отмене брони (read-only).

## Requirements
CHAT-ENH-01..04

## Success Criteria
1. Изображения/документы отправляются и отображаются.
2. Статусы прочтения работают.
3. Шаблоны быстрых ответов доступны владельцу.
4. Антиспам блокирует спам.

## Key Tasks
- Модель ChatAttachment (или использование существующей).
- Загрузка файлов (S3).
- Статусы прочтения (read receipts).
- Шаблоны сообщений (CRUD).
- Антиспам (rate limit, фильтр).
