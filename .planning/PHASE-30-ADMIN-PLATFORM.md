# Phase 30: Admin platform

## Overview
Роли администраторов, конфигурируемые параметры платформы, SLA поддержки, антифрод, SEO/баннеры/коллекции, углублённый аудит.

## Goal
- Роли: superadmin, moderator, support, finance, marketing, content-manager.
- Конфигурируемые параметры (мин. длительность, шаг, буфер, комиссия, лимиты фото, срок отзыва, рекламные места, видимость контактов, разрешения) — в админке.
- SLA поддержки (время ответа, назначение, статусы).
- Антифрод (массовые отмены, подозрительные отзывы, спам, дубли, накрутка).
- SEO-страницы, баннеры, коллекции — управление без программиста.
- Углублённый аудит (до/после, IP, объект изменения).
- Маркировка рекламы.

## Requirements
ADMIN-PLAT-01..07

## Success Criteria
1. Роли ограничивают доступ корректно.
2. Параметры настраиваются из админки.
3. SLA контролируется.
4. Антифрод выявляет аномалии.
5. SEO/баннеры/коллекции редактируются в админке.

## Key Tasks
- Расширить Role enum.
- Таблица PlatformSettings (key/value).
- SLA-метрики в тикетах.
- Антифрод-правила.
- CRUD для SEO/banners/collections.
- Углублённый аудит.
