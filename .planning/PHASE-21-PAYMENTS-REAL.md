# Phase 21: Real payments integration

## Overview
Замена mock-провайдера реальным платежным шлюзом (CloudPayments/YooKassa), проверка подписи вебхуков, чеки, возвраты.

## Goal
- Интеграция с реальным провайдером (CloudPayments/YooKassa).
- Проверка подписи вебхуков (HMAC).
- Отправка чеков (онлайн-касса).
- Повторная попытка оплаты, обработка ошибок.

## Requirements
PAY-REAL-01, PAY-REAL-02, PAY-REAL-03

## Success Criteria
1. Платеж инициируется через реальный шлюз.
2. Вебхук проверяется по подписи.
3. Чек отправляется автоматически.
4. Возвраты выполняются через админку.

## Key Tasks
- Настроить провайдера, env-ключи.
- Реализовать verifySignature в webhook handler.
- Интегрировать с онлайн-кассой.
- Добавить retry-логику.
- Обновить тесты.
