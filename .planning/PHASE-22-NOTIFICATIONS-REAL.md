# Phase 22: Real notifications (email/SMS/Telegram/WhatsApp)

## Overview
Замена mock-уведомлений реальными каналами: email, SMS, Telegram, WhatsApp, push. Шаблоны с переменными, логирование доставки, резервный канал.

## Goal
- Реальные провайдеры email (SendGrid/SES) и SMS (Twilio).
- Telegram/WhatsApp интеграция для владельцев.
- Шаблоны уведомлений с переменными (имя, объект, дата, время, сумма, ссылка).
- Логирование доставки, retry при ошибках.
- Резервный канал (email при ошибке мессенджера).

## Requirements
NOTIF-REAL-01, NOTIF-REAL-02, NOTIF-REAL-03

## Success Criteria
1. Клиент получает подтверждение бронирования по email/SMS.
2. Владелец получает уведомление о новой заявке в Telegram.
3. Шаблоны редактируются в админке.
4. Ошибки доставки логируются.

## Key Tasks
- Подключить email/SMS провайдеры.
- Реализовать Telegram bot для уведомлений владельцев.
- Шаблонизатор с переменными.
- Логирование и retry.
- Тестирование каналов.
