# Phase 25: Search and ranking

## Overview
Интеграция поискового движка (Meilisearch), автодополнение, сохранённые поиски, «рядом со мной», фильтры по району/метро.

## Goal
- Meilisearch/Elasticsearch для быстрого поиска.
- Поиск по названию, адресу, району, типу, услугам, ключевым словам.
- Автодополнение городов, районов, услуг, популярных запросов.
- Фильтры: район, метро, ценовой сегмент, рейтинг, видео, дети, животные, мероприятия.
- Сохранение поисковых параметров в сессии.
- «Рядом со мной» (геолокация).
- Подписка на появление свободных окон.

## Requirements
SEARCH-01..04

## Success Criteria
1. Поиск <1с на типовых объёмах.
2. Автодополнение работает.
3. Геолокация фильтрует по расстоянию.
4. Сохранённые поиски для авторизованных.

## Key Tasks
- Подключить Meilisearch.
- Индексация venues.
- Автодополнение API.
- Геолокация (IP/browser).
- Сохранение поисков в профиле.
