# Phase 33: NFR and monitoring

## Overview
Нефункциональные требования: производительность, доступность, логирование, мониторинг, кэширование, бэкапы, нагрузочное тестирование.

## Goal
- Производительность: главная <2–3с, поиск <1с, API 95% <300–500мс.
- Доступность 99.5%+: резервное копирование БД и файлов, восстановление.
- Логирование: системные, ошибок, платежей, уведомлений, метрики.
- Алерты при сбоях.
- Кэширование справочников и популярных запросов (Redis).
- Асинхронная обработка изображений и уведомлений.
- Нагрузочное тестирование.
- Мониторинг производительности.

## Requirements
NFR-01..05

## Success Criteria
1. API 95% <500мс на типовых объёмах.
2. Бэкапы настроены и проверены.
3. Мониторинг и алерты работают.
4. Кэш ускоряет каталог/поиск.
5. Нагрузочные тесты пройдены.

## Key Tasks
- Настроить Redis-кэш.
- Бэкапы БД (pg_dump + cron).
- Мониторинг (Prometheus/Grafana или аналог).
- Нагрузочные тесты (k6/artillery).
- Оптимизация изображений (sharp).
- Алерты.
