# Requirements: Портал для аренды бань и саун

## v1 Requirements

### Поиск и каталог

- [x] **CAT-01**: Выбор города с сохранением выбора
- [x] **CAT-02**: Каталог объектов с фильтрами (дата/время/длительность/человек/цена/услуги/тип/район/удобства)
- [x] **CAT-03**: Сортировка и карта с кластерами
- [x] **CAT-04**: Карточка объекта с галереей, видео, описанием, удобствами, правилами, календарём

### Бронирование

- [x] **BOOK-01**: Форма бронирования с проверкой доступности
- [x] **BOOK-02**: Предотвращение пересечений и двойных броней
- [x] **BOOK-03**: Режимы (подтверждение/мгновенное с оплатой/оплата на месте)
- [x] **BOOK-04**: Доп.услуги при бронировании

### Кабинеты

- [x] **AUTH-01**: Регистрация/авторизация, роли, JWT
- [x] **USER-01**: ЛК клиента (бронирования, избранное, отзывы, чаты)
- [x] **PART-01**: Кабинет партнёра (объекты, календарь, брони, доп.услуги, фото)
- [x] **PART-02**: iCal импорт/экспорт с обработкой конфликтов
- [x] **ADMIN-01**: Админ-панель (модерация, пользователи, брони, платежи, аналитика)

### Коммуникации и контент

- [x] **CHAT-01**: Чат клиента и владельца привязанный к бронированию
- [x] **REV-01**: Отзывы и рейтинги с модерацией и ответами владельца
- [x] **PROM-01**: Промокоды и платное продвижение

### Системное

- [x] **PAY-01**: Платежи (карта/СБП), статусы, возвраты
- [x] **NOTIF-01**: Уведомления (email/SMS/push/мессенджеры)
- [x] **SEC-01**: Ролевая модель, защита от IDOR/XSS/CSRF, аудит критичных действий
