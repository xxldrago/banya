         - If ADMIN: all conversations
         - Include booking, participants, last message preview
         - Return array of conversations

       - getConversationById(conversationId: string, userId: string, role: string):
         - Fetch conversation with participants
         - Check access: if role === "ADMIN", allow; else check if user is participant
         - If not participant and not admin: throw ChatAccessDenied
         - Return conversation

       - getMessages(conversationId: string, userId: string, role: string, limit: number, cursor?: string):
         - Check conversation access (same as above)
         - Fetch messages ordered by createdAt ASC (or DESC? check context — likely ASC for chat)
         - If cursor provided, fetch messages after that ID
         - Return array of messages with sender info

       - sendMessage(conversationId: string, userId: string, body: string):
         - Check conversation access (must be participant or admin)
         - Create ChatMessage: { conversationId, senderId: userId, body }
         - Return message with sender

       - isParticipant(conversationId: string, userId: string): boolean — helper
