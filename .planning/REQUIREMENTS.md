# Requirements: Портал для аренды бань и саун

## v1 Requirements

### Поиск и каталог

- [x] **CAT-01**: Выбор города с сохранением выбора
- [ ] **CAT-02**: Каталог объектов с фильтрами (дата/время/длительность/человек/цена/услуги/тип/район/удобства)
- [ ] **CAT-03**: Сортировка и карта с кластерами
- [x] **CAT-04**: Карточка объекта с галереей, видео, описанием, удобствами, правилами, календарём

### Бронирование

- [ ] **BOOK-01**: Форма бронирования с проверкой доступности
- [ ] **BOOK-02**: Предотвращение пересечений и двойных броней
- [ ] **BOOK-03**: Режимы (подтверждение/мгновенное с оплатой/оплата на месте)
- [ ] **BOOK-04**: Доп.услуги при бронировании

### Кабинеты

- [ ] **AUTH-01**: Регистрация/авторизация, роли, JWT
- [ ] **USER-01**: ЛК клиента (бронирования, избранное, отзывы, чаты)
- [ ] **PART-01**: Кабинет партнёра (объекты, календарь, брони, доп.услуги, фото)
- [ ] **PART-02**: iCal импорт/экспорт с обработкой конфликтов
- [ ] **ADMIN-01**: Админ-панель (модерация, пользователи, брони, платежи, аналитика)

### Коммуникации и контент

- [ ] **CHAT-01**: Чат клиента и владельца привязанный к бронированию
- [ ] **REV-01**: Отзывы и рейтинги с модерацией и ответами владельца
- [ ] **PROM-01**: Промокоды и платное продвижение

### Системное

- [ ] **PAY-01**: Платежи (карта/СБП), статусы, возвраты
- [ ] **NOTIF-01**: Уведомления (email/SMS/push/мессенджеры)
- [ ] **SEC-01**: Ролевая модель, защита от IDOR/XSS/CSRF, аудит критичных действий
