# Phase 26: Pricing and tariffs

## Overview
Расширенное ценообразование: тарифы по дням/часам, спецпредложения, динамическое ценообразование.

## Goal
- Цена в будни/выходные/праздники/ночной тариф.
- Пакеты часов.
- Спецпредложения: скидка на даты, счастливый час, скидка на длительный период, скидка на будни, скидка на первое бронирование.
- Расчёт итоговой стоимости: часы + тариф + услуги + промокод + депозит + комиссия.
- Тарифы владельца (Tariff модель уже есть) — UI и логика применения.

## Requirements
PRICING-01..03

## Success Criteria
1. Тариф зависит от дня/времени.
2. Спецпредложения применяются автоматически.
3. Итоговая стоимость учитывает все компоненты.

## Key Tasks
- Расширить модель Venue/Booking (тарифы по датам).
- Логика расчёта цены.
- UI спецпредложений.
- Применение тарифов при бронировании.
