# Phase 32: Extra features

## Overview
Дополнительный функционал: лист ожидания, подарочные сертификаты, пакетные предложения, углублённая лояльность, сравнение объектов, маршрут до объекта, AI-подбор.

## Goal
- Лист ожидания (waitlist) при занятом объекте + уведомление при освобождении.
- Подарочные сертификаты (покупка, отправка по email).
- Пакетные предложения (ДР, романтический вечер, корпоратив, ночь в сауне).
- Углублённая лояльность (баллы за брони/отзывы/приглашения, уровни).
- Сравнение объектов (по цене, вместимости, удобствам, рейтингу).
- Маршрут до объекта (интеграция с картами).
- AI-подбор (чат-бот/форма).

## Requirements
EXTRA-01..07

## Success Criteria
1. Лист ожидания работает и уведомляет.
2. Сертификаты покупаются и отправляются.
3. Пакеты доступны при бронировании.
4. Сравнение и маршрут работают.
5. AI-подбор возвращает релевантные объекты.

## Key Tasks
- Waitlist API + UI + уведомления.
- Сертификаты (модель, оплата, email).
- Пакеты (модель, UI).
- Лояльность (баллы, уровни, правила).
- Сравнение (UI).
- Маршрут (карты).
- AI-подбор (LLM-интеграция).
